# CASE STUDY 2: ỨNG DỤNG QUẢN LÝ VÀ GIAO CÔNG VIỆC NHÓM

## Thông tin sinh viên
- **Họ và tên:** Nguyễn Nhựt Duy
- **Mã số sinh viên:** KHMT2411073

## Cấu trúc dự án
- `api/`: Backend Node.js / Express / REST API / MongoDB Atlas.
- `TaskManager/`: Frontend ứng dụng Flutter.

## Hướng dẫn khởi chạy
### Backend (api)
1. `cd api`
2. `npm install`
3. Đổi tên `.env.example` thành `.env` và điền thông tin MongoDB Atlas, JWT Secret, SMTP Email.
4. `npm run dev`

### Frontend (TaskManager)
1. `cd TaskManager`
2. `flutter pub get`
3. `flutter run`
